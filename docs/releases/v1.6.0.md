Stability release: it fixes the random reboots, freezes and zeroed or missing values that appeared since v1.5.0, and hardens the whole USB layer so the board recovers by itself when the UPS link misbehaves.

## ⚠️ Upgrade notes

- **Full flash required once.** Boards on **v1.5.x or earlier** must install this version with the [web installer](https://maverick1982.github.io/esp32-nut/), not via OTA: OTA cannot add the new `coredump` partition. Leave *Erase device* unchecked to keep the Wi-Fi and NUT settings. Later updates can use OTA again.
- **`ups.status` while on battery** is now `OB DISCHRG` instead of `OB`, as upstream NUT does. `upsmon` still acts on `OB` / `LB`; check any automation that matches the exact string.
- **No UPS attached:** NUT clients now get `ERR DATA-STALE` (also when the data can no longer be refreshed), instead of an empty `Unknown` status.
- **Polling cadence:** status values refresh every 2 s, the other values every 30 s, like `usbhid-ups`. Before, every report was read every 2 s.

## Fixes

- **All brands:** after some hours values dropped to `0` or disappeared, and the board could reboot, crash or freeze. Since v1.5.0 a USB request could deadlock with an incoming report; from then on every answer belonged to the previous request. ([#47](https://github.com/maverick1982/esp32-nut/issues/47)) The same fix should also help with [#48](https://github.com/maverick1982/esp32-nut/issues/48) and [#36](https://github.com/maverick1982/esp32-nut/issues/36).
- **Web UI and NUT:** they no longer slow down or stop answering while the firmware waits for the UPS.
- **Eaton:** `ups.status` showed `OL OB` on battery.
- **Beeper:** changing the beeper could also write zeros to other settings of the same report, such as the shutdown delay.
- **Web installer:** a board updated an odd number of times via OTA kept booting the old firmware after a full flash.

## Other changes

- **Automatic recovery:** when the UPS stops answering, the firmware retries, resets the USB link and, as a last resort, restarts the board with increasing delays (1 / 5 / 15 min), then shows a degraded-mode banner in the web UI.
- **Crash diagnostics:** a task watchdog replaces the old timer watchdog, and the web UI shows the reset reason and a summary of the last crash.
- **UPS strings:** values such as `battery.type` are now read from the UPS.
- **Logs:** one traffic summary every 60 s replaces one line per report; heap and stack diagnostics added.

## Install

Flash it from the [web installer](https://maverick1982.github.io/esp32-nut/): this is required when coming from v1.5.x or earlier (see the upgrade notes).
