Bug-fix release for APC owners: it ends the boot loop some Back-UPS models caused as soon as they were plugged in, and brings back the load, real power and nominal voltages on APC units.

## ⚠️ Upgrade notes

- **Coming from v1.5.x or earlier:** install with the [web installer](https://maverick1982.github.io/esp32-nut/), not with an OTA update. v1.6 added a flash partition that an OTA cannot create. From v1.6.0 onwards, OTA works as usual.
- **APC:** `input.voltage.nominal` could show the battery nominal voltage (e.g. 12 V) instead of the mains one (e.g. 230 V). The battery value now goes to `battery.voltage.nominal`, as in NUT: if a dashboard or automation relied on the old value, update it.

## Fixes

- **APC Back-UPS BX1500G, ES 850G2, BE650G2:** the ESP32 crashed and rebooted in a loop as soon as the UPS was connected (regression since v1.5.3). ([#55](https://github.com/maverick1982/esp32-nut/issues/55))
- **APC Back-UPS CS:** `ups.load` and `ups.realpower` were empty again since v1.5.0. ([#48](https://github.com/maverick1982/esp32-nut/issues/48))
- **APC, CyberPower:** nominal input and battery voltages were mixed up or missing since v1.5.0. ([#48](https://github.com/maverick1982/esp32-nut/issues/48))
- **Web UI:** a real power of 0 W was shown as `--`. ([#48](https://github.com/maverick1982/esp32-nut/issues/48))

## Other changes

- Release workflow moved to the Node 24 versions of its GitHub Actions.
