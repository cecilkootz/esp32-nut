Feature release: it adds EcoFlow River 3 Plus / Delta 3 Plus portable power stations, brings back the missing readings on the Powercom SPD-750U, and makes `ups.status` report more of what the UPS knows, the way upstream NUT does.

## ⚠️ Upgrade notes

- **Coming from v1.5.x or earlier:** install with the [web installer](https://maverick1982.github.io/esp32-nut/), not with an OTA update: v1.6 added a flash partition that an OTA cannot create. From v1.6.0 onwards, OTA works as usual.
- **`ups.status` can show new tokens**, as upstream `usbhid-ups` does ([#62](https://github.com/maverick1982/esp32-nut/issues/62)):
  - `LB` also when the UPS says its remaining runtime limit has expired;
  - `RB` also when the UPS says no battery is present (ignored on OpenUPS / WalleCube, which report it wrongly);
  - `DISCHRG` disappears once the UPS reports the battery as fully discharged.
- **`CHRG` at 100 %:** on UPS models that do not report a *fully charged* flag, `CHRG` now appears only while `battery.charge` is between 0 and 100 %, as upstream. A full battery on mains no longer shows `OL CHRG`, just `OL`. Check automations that match the exact status string.
- **`battery.voltage.nominal` is rounded, not truncated** ([#67](https://github.com/maverick1982/esp32-nut/issues/67)): a 12.9 V value now reads `13` instead of `12`. On **APC** it has one decimal, as in NUT (`12.0` instead of `12`).

## New and improved UPS support

- **EcoFlow River 3 Plus, Delta 3 Plus** (VID `0x3746`): new driver based on the upstream NUT `ecoflow-hid` subdriver. It adds battery runtime in seconds (the device reports minutes), capacity and warning level, nominal battery voltage and power, battery type and the outlet timers. The beeper status is shown read-only: these devices ignore the beeper commands, so the web UI toggle and the NUT `beeper.*` commands are hidden. **Untested on real hardware**: feedback and USB diagnostics are welcome. ([#61](https://github.com/maverick1982/esp32-nut/issues/61))
- **Powercom SPD-750U:** `battery.temperature` and the beeper status are back, `battery.voltage` is no longer empty, and `ups.mfr` shows `POWERCOM Co.,LTD`. Requests to the UPS are now spaced out, so it no longer stops answering during the full poll. ([#36](https://github.com/maverick1982/esp32-nut/issues/36))
